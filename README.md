# Flow Inventory

Live multi-developer inventory, pricing and booking platform for Flow Realty.

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # unit + golden pricing tests
npm run lint && npm run typecheck && npm run build
```

Start with `docs/PROGRESS.md`, then `docs/ARCHITECTURE.md` and `docs/DECISIONS.md`. Environment variable names are in `.env.example`.
